## Welcome to Yapindo Frontend 👋

We're the frontend team at PT Yapindo Jaya Abadi, in Indonesia. We build the web and desktop apps behind Yapindo's products: tryout and exam-prep sites, book platforms, a marketplace, and the dashboards that run them.

Most of our code is private. What all our projects share:

- **yaplib**, our frontend libraries: **folio**, a Svelte reader for PDF and EPUB books, with annotations and themes; **countdown**, timers to a deadline that never drift; and **docs-mcp**, which gives AI coding agents our docs.
- **The frontend handbook**, how we work in every project: branches and reviews, code standards, layout, accessibility, writing, security, and what "done" means.

### On the team?

Start with [Your first week](https://yaplib-site.pages.dev/handbook/first-week/) in the handbook ([Bahasa Indonesia](https://yaplib-site.pages.dev/id/handbook/first-week/)), then the README and CONTRIBUTING of the project you're joining. The docs site asks you to sign in with GitHub and lets in members of this organization. Something wrong or missing in the handbook? Fix it in [yaplib](https://github.com/yapindo-frontend/yaplib): it's the most useful first pull request you can make.
